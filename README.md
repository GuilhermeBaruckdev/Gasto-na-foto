# Gasto na Foto

Aplicação web para registrar gastos a partir de fotos de comprovantes.

O usuário pode fotografar ou selecionar a imagem de um comprovante. A IA identifica os itens e o valor total; depois, o valor pode ser conferido e editado antes de ser salvo.

## Funcionalidades

- Envio de foto pela câmera ou galeria
- Leitura de comprovantes com IA
- Conferência e edição manual do valor identificado
- Lista de comprovantes registrados
- Soma do total de gastos
- Dados salvos no navegador com `localStorage`
- Layout responsivo para celular e computador

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Puter AI

## Como usar

1. Abra o projeto no navegador ou com a extensão Live Server.
2. Toque em “fotografar o comprovante”.
3. Escolha ou tire uma foto nítida.
4. Confira os itens e o valor total encontrados.
5. Clique em “Salvar gasto”.

> Os dados ficam salvos apenas no navegador utilizado. Sempre confira os valores identificados antes de salvar.
